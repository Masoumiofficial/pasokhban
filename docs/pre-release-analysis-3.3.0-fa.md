## ۲) آنچه تأیید شد ✅

**بسته و نسخه**
- ۳۹ فایل، ریشۀ داخل zip پوشۀ `pasokhban/`؛ `unzip -t` بدون خطا؛ مجوزها ۶۴۴ فایل / ۷۵۵ پوشه.
- یکدستی نسخه: `Version: 3.3.0` = `PASOKHBAN_VERSION` = `Stable tag: 3.3.0` و نخستین بند Changelog = `3.3.0`.
- هیچ ارجاعی به سبک حذف‌شده نمانده (`widget_style`، `#pasokhban-root`، `handle_config`، `stt/tts`، `ETEHADYAR`): صفر در مسیرهای اجرایی؛ فقط ۳ خط توضیح در کامنت‌ها.

**کد**
- پارس کامل ۲۲ فایل PHP با دستور زبان **PHP 7.4 و 8.3** (php-parser 3.7): صفر خطا.
- هیچ ساختار اختصاصی PHP 8 (`?->`، `match`، `enum`، `readonly`، `str_contains`…) پیدا نشد → ادعای «PHP 7.4+» معتبر است.
- پارامتر nullable ضمنی (`string $x = null`) صفر است → در PHP 8.4 هم Deprecated نمی‌گیرد.
- **فراخوانی استاتیکِ متد نمونه (قاتل ۳.۲.۸): صفر.** ممیزی روی همهٔ `Pasokhban*::method()`.
- ۲۰۰ `echo` در PHP؛ فقط **یک** مورد بدون escape و آن هم `echo $json` با برچسب `phpcs:ignore` (عمدی) است؛ ۱۱۴ مورد با `esc_*`.
- SQL: ۴۰ مورد `$wpdb->prepare`؛ تنها جاسازی‌ها درون رشته، **نام جدول** از `Pasokhban_DB::*_table()` است (نه ورودی کاربر) → راه تزریق SQL نیست.
- ورودی‌ها در REST با `sanitize_textarea_field`/`sanitize_key` + سقف طول (۴۰۰۰ نویسه) پاک‌سازی می‌شوند؛ `intval/min/max` روی همهٔ عدد‌ها.
- ضمیمه‌ها: کلاینت **توکن** می‌فرستد نه URL؛ توکن به `session_id` مقید است (`resolve_tokens`) ✓ الگوی درست.
- آپلود: فهرست سفید `jpg jpeg png gif webp txt` (SVG و اجرایی ممنوع)، بررسی نوع محتوا با `wp_check_filetype_and_ext` + `finfo`، نام تصادفی، `.htaccess` و `Deny` روی پوشه، سقف تعداد در پیام (۴) و در انتظار (۱۲)، نرخ‌محدود در باکت جدا.

**دسترسی‌ها (۱۹ مسیر REST)**
| گروه | مجوز |
|---|---|
| `/admin/delete` | `Pasokhban_Team::is_admin()` |
| `/admin/assign`، `/admin/agents`، `/admin/order`، copilot | `Pasokhban_Team::can_access()` (نقش اپراتور) |

- ۵ هندلر `admin_post_*` همگی `check_admin_referer`/`current_user_can` دارند (۵/۵).
- `get_option('pasokhban_options', false)` → آپشن با autoload خاموش ✓ روی سایت شلوغ بار اضافی ندارد.
- کشوی داده: `retention_days` + `wp_schedule_event('pasokhban_daily_cleanup')` و `wp_unschedule_event` در زمان درست ✓.
- کد اشکال‌زدایی: `var_dump`/`print_r`/`console.log`/`TODO`/`FIXME`/`debugger` صفر. تنها `error_log` عمدی و لازم است (شکست ذخیرۀ تنظیمات در فعال‌سازی).

## ۳) بلوکرهای انتشار (پیش از زدن دکمهٔ امروز)

1. **لینک راهنمای آنلاین ۴۰۴ است.** `etehadwp.com/pasokhban/guide.html` در README عمومی (جدول «مستندات» + فوتر) و README خصوصی لینک شده. یا صفحۀ `guide.html` را بساز/منتشر کن، یا لینک را به همان PDF و `docs/guide-fa.md` در مخزن عمومی تغییر بده. انتشار با لینک شکسته = اولین تجربهٔ بد خریدار.
2. **مخزن عمومی ۸ نسخه عقب است و دسترسی پوش نداریم.** بستۀ آماده `pasokhban-github-repo.zip` (۲۱ فایل، بج ۳.۳.۰، PDF ۷ صفحۀ جدید، FAQ با پرسش «صدا چرا حذف شد») در مخزن خصوصی است؛ باید روی `etehadwp/pasokhban` قرار بگیرد.
3. **قیمت و لینک خرید نهایی نشده.** صفحهٔ محصول نوشته «قیمت‌ها و سطح‌های لایسنس هنوز نهایی نیستند / لینک خرید پس از نهایی‌شدن فعال می‌شود». اگر منظورت از انتشار «فروش» است، این گلوگاه اصلی است، نه افزونه.
4. **`Tested up to: 6.6`** در حالی‌که وردپرس پایدار امروز **۷.۱.۳** است (۶ اکتبر ۲۰۲۶) و چرخۀ ۷.۲ در بتا. عدد غلط نیست ولی اعتبار فنی را می‌گیرد. یا روی یک تست‌باکس ۶.۹/۷.۱ اجرای واقعی بگیر و عدد را بالا ببر، یا در متن فروش صریح بنویس «تست‌شده تا ۶.۶، سازگار با ۷.x بر پایهٔ API پایدار».
5. **هدر GPL در برابر بج «proprietary».** سر صفحۀ افزونه `License: GPL-2.0-or-later` و `readme.txt` هم `GPLv2 or later`، ولی بج مخزن عمومی `license-proprietary` است. برای محصول فروشیِ سورس‌بسته در اکوسیستم وردپرس معمول همین است (GPL برای کاربران، سورس عمومی نه)، اما **یکی** را انتخاب و همه‌جا یکسان کن — این تناقض در هر دو جا مشتری حرفه‌ای را شک‌برانگیز می‌کند.

## ۵) چک‌لیست پیشنهادی برای همین امروز

1. تصمیم‌های متن باز: پیش‌فرض `uninstall_delete_data`، پیش‌فرض `cdn_font`، چارچوب لایسنس (GPL vs proprietary). هر سه یک‌خطی‌اند و اگر بگویی در ۳.۳.۱ انجام می‌شود.
2. انتشار مستندات عمومی: بازکردن `pasokhban-github-repo.zip` روی `etehadwp/pasokhban` (یا با حساب خودت پوش کن؛ من از این محیط فقط pull دارم).
3. رفع لینک ۴۰۴: یا build صفحۀ `guide.html` از `docs/guide-fa.md`، یا حذف لینک و ارجاع به PDF.
4. افزودن asset رسمی zip به ریلیز گیت‌هاب از مرورگر خودت (اگر می‌خواهی لینک `raw/main` جای آن را نگیرد) و درج sha256 در صفحه.
5. یک اجرای دستی روی یک تست‌باکس ۷.۱.x: فعال‌سازی، «بررسی سلامت» سبز، ارسال فایل، استریم SSE، اعلان تلگرام/بله. اگر سبز بود، `Tested up to` را به ۷.۱ ببر و دوباره بسته‌بندی کن (عدد در readme فقط، بدون تغییر کد).
6. پیام انتشار برای لیست مشتریان: «۳.۳.۰ = حذف سبک مغز کیهانی و صدا؛ بدون مهاجرت دیتابیس؛ اگر روی آن سبک بودید، خودکار چت شیشه‌ای را می‌گیرید».
