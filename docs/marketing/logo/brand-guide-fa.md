# نشان برند گپینه — راهنمای کوتاه

نشانِ گپینه یک **حبابِ گفتگو** است: مربعِ گوشه‌گرد با دنبالهٔ حرف‌زدن، و داخلش حرفِ
**«گ»** (از «گپینه»). حرف از فونت **وزیرمتن Black** به مسیر تبدیل شده، پس فایل SVG
به هیچ فونت یا نرم‌افزاری وابسته نیست.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `brand-mark.svg` | نشانهٔ اصلی (۶۴×۶۴) — منوی پیشخوان، هدر تنظیمات، آواتار ویجت |
| `brand-mark-mono.svg` | تک‌رنگ تیره، برای زمینهٔ روشن و چاپ تک‌رنگ |
| `brand-mark-white.svg` | تک‌رنگ سفید، برای زمینهٔ تیره |
| `logo-horizontal.svg` | لوک‌آپ افقی (نشانه + «گپینه») برای زمینهٔ روشن |
| `logo-horizontal-light.svg` | لوک‌آپ افقی برای زمینهٔ تیره |
| `logo-horizontal-tagline.svg` | لوک‌آپ با شعار «چت هوشمند و پشتیبانی آنلاین» |
| `brand-mark-512.png` | خروجی PNG برای فروشگاه/شبکه‌های اجتماعی |

## رنگ‌ها

| نقش | مقدار |
|---|---|
| آبی فیروزه‌ای (شروع گرادیان) | `#22d3ee` |
| نیلی (پایان گرادیان) | `#6366f1` |
| متن اصلی | `#0f172a` |
| متن کم‌رنگ | `#475569` |

گرادیان همیشه مورب و از بالا-چپ به پایین-راست است.

## قواعد استفاده

- **حداقل اندازه:** ۲۰ پیکسل برای نشانه. زیر ۲۰ پیکسل از نسخهٔ تک‌رنگ استفاده کنید.
- **حاشیهٔ آزاد:** دست‌کم به اندازهٔ یک‌چهارم عرض نشانه، در هر چهار طرف خالی بماند.
- **نسبت:** نشانه همیشه مربع است؛ کشیدگی افقی/عمودی ممنوع.
- **روی زمینهٔ تیره:** فقط `brand-mark-white.svg` یا لوک‌آپ light.
- **بدون تغییر:** دنبالهٔ حباب را جابه‌جا نکنید، حرف «گ» را با متن زنده عوض نکنید،
  و نشانه را داخل شکل یا قاب دیگری نگذارید.

## بازتولید

فایل‌ها با `tools/build-logo.py` بازتولید می‌شوند (وزیرمتن + HarfBuzz برای چسبیدن
حروف). همین هندسه در `assets/img/brand-mark.svg` و در آیکن منوی پیشخوان
(`MENU_ICON` در `includes/class-settings.php`) استفاده شده است.
