# راه‌اندازی لایسنس راست‌چین روی گپینه — چک‌لیست

آخرین به‌روزرسانی: با فایل واقعی `RTL_License_b0e384722fc261db.php` (۴۰٬۳۵۱ بایت،
sha1 `5210705e…` که دقیقاً با هش راهنمای راست‌چین می‌خواند).

## ۱) ساختار نهایی

| فایل | چه کسی می‌سازد | در بستهٔ نصب؟ |
|---|---|---|
| `RTL_License_b0e384722fc261db.php` (ریشهٔ افزونه) | **راست‌چین** (ionCube) | بله — کتابخانهٔ لایسنس |
| `gapineh-license.php` (ریشهٔ افزونه) | ما (قطعه‌کد مرحلهٔ اول راهنما) | بله — خوانا |
| `includes/class-license-status.php` | ما (لایهٔ نمایش و دروازه) | بله — خوانا |
| `gapineh.php` | ما (بارگذاری با نگهبان) | بله |

نکتهٔ کلیدی که در نگاه اول گمراه‌کننده است: فایل `RTL_License_…php` که از راست‌چین گرفتی
**فایل لایسنس خریدار نیست**، خودِ کتابخانهٔ لایسنس است که باید در همهٔ نسخه‌های محصول
حضور داشته باشد (به همین دلیل هشش با هشِ داخل قطعه‌کد یکی است). خریدار چیزی آپلود نمی‌کند.

## ۲) کاری که انجام شد

قطعه‌کد راهنما **عیناً** داخل `gapineh-license.php` است: همان نام کلاس، همان هش
`5210705eb2491e92815cd01b5877475e4a69fcba`، `__DIR__`، `sha1_file`، `isActive()`.
تنها افزودهٔ ما داخل شاخهٔ `// Product is Active Now, Enable Pro Features`:

```php
if ( ! defined( 'GAPINEH_PRO' ) ) { define( 'GAPINEH_PRO', true ); }
do_action( 'gapineh_pro_active' );
```

**نکتهٔ حیاتی — ionCube:** کتابخانهٔ راست‌چین رمزنگاری‌شده است. اگر روی سرور مشتری
`ionCube Loader` نباشد، آن فایل به‌جای اجرا پیام Script error چاپ می‌کند و با `exit(199)`
کل بارگذاری را متوقف می‌کند — یعنی سایت سفید. برای همین **دو نگهبان** گذاشته‌ام:

1. در `gapineh.php`: `gapineh-license.php` فقط وقتی بارگذاری می‌شود که
   `extension_loaded('ionCube Loader')` (یا `ioncube_loader_version()`) true باشد.
2. در خود `gapineh-license.php`: حتی اگر مستقیم صدا زده شود، بلاک راست‌چین داخل همین شرط است.

خروجی: روی هاست بدون Loader، افزونه در **حالت آزاد** کار می‌کند و پیام
«این سرور ionCube Loader ندارد» با راهنما در پیشخوان نشان داده می‌شود — نه صفحهٔ سفید.

## ۳) چهار وضعیت در پیشخوان

| وضعیت | معنی | رنگ |
|---|---|---|
| `active` | `isActive()` مقدار true داد؛ `GAPINEH_PRO` تعریف شد | سبز |
| `inactive` | کتابخانه بارگذاری شد ولی لایسنس فعال نیست | قرمز + اعلان |
| `hash_mismatch` | فایل کتابخانه هست ولی با هش نمی‌خواند (بستهٔ ناقص/دست‌کاری‌شده) | قرمز + اعلان |
| `no_loader` | ionCube Loader روی سرور نیست | کهربایی + اعلان |
| `lib_missing` | کتابخانهٔ لایسنس در بسته نیست | کهربایی + اعلان |

## ۴) مرحلهٔ «رمزنگاری» راهنمای راست‌چین

راهنما می‌گوید فایلی را که کد را در آن گذاشتی در پنل آپلود کن و نسخهٔ encode شده را
جایگزین کن. دو حالت:

- **پیشنهاد من: انجام نده.** محتوای فایل ما فقط یک `define` است؛ رمزنگاری‌اش چیزی را
  محافظت نمی‌کند، ولی یک ریسک اضافه می‌آورد (همان نیاز به ionCube Loader) و هر تغییر بعدی
  را هم قفل می‌کند.
- **اگر انجام دادی:** مشکلی نیست؛ نگهبان داخل `gapineh.php` جلوی صفحهٔ سفید را می‌گیرد.
  بعد از رمزنگاری، `verify-release.py` خودش می‌فهمد فایل رمزشده است و بررسی متنی را
  رد می‌کند (هشدار می‌دهد، خطا نمی‌دهد).

اگر زمانی تصمیم گرفتی رمزنگاری کنی، مسیرش این است:

```bash
bash tools/pack-release.sh /path/to/gapineh 1.0.0 \
     --encoded-license ~/Downloads/gapineh-license.php \
     --out ./gapineh.1.0.0.zip
```

## ۵) بسته‌سازی

`tools/pack-release.sh` حالا:

1. کتابخانهٔ لایسنس را از ریشهٔ مخزن (`RTL_License_b0e384722fc261db.php`) برمی‌دارد و در
   ریشهٔ افزونه می‌گذارد (اگر با `--license-lib` مسیر دیگری بدهی، همان را).
2. **sha1 آن را با هش رسمی چک می‌کند**؛ اگر نخواند، بسته ساخته نمی‌شود.
3. اگر `RTL_License_*.php` دیگری در بسته باشد، رد می‌کند.
4. `verify-release.py` را اجرا می‌کند (دروازهٔ ۱۰: کتابخانه + نگهبان + قطعه‌کد + وضعیت‌ها).

## ۶) چک‌لیست روی هاست تست

1. [ ] نصب روی هاست **با** ionCube Loader → ردیف وضعیت باید «لایسنس غیرفعال است» یا
       «لایسنس فعال است» باشد (بسته به این‌که فعال‌سازی انجام شده یا نه) — نه `no_loader`.
2. [ ] اگر «غیرفعال» بود: مسیر فعال‌سازی همان است که افزونه/راست‌چین نشان می‌دهد.
3. [ ] نصب روی هاست **بدون** ionCube Loader → افزونه باید کامل کار کند و فقط ردیف
       کهربایی «این سرور ionCube Loader ندارد» را نشان دهد. **سایت نباید سفید شود.**
4. [ ] `unzip -l gapineh.1.0.0.zip | grep RTL_License` → باید یک فایل بدهد.
5. [ ] `php -r "var_dump(extension_loaded('ionCube Loader'));"` روی هاست تست.

## ۷) سه هشدار

- **GPL در برابر فعال‌سازی:** هدر افزونه `GPL-2.0-or-later` است؛ GPL اجازهٔ گذاشتن محدودیت
  فعال‌سازی روی توزیع نمی‌دهد. بیشتر محصولات ایرانی این کار را می‌کنند و پیگیری هم نمی‌شود،
  ولی آگاهانه تصمیم بگیر: هدر تجاری شود، یا نسخهٔ آزاد واقعاً آزاد بماند و پرو جدا فروخته شود.
- **ionCube روی هاست‌های اشتراکی:** معمولاً فعال است و از پشتیبانی هاست یک‌کلیکی روشن می‌شود؛
  ولی روی بعضی هاست‌های ارزان خاموش است. همین حالا از هاست خودت بپرس.
- **فایل کتابخانه در مخزن عمومی:** `Masoumiofficial/pasokhban` عمومی است و این فایل هم
  آنجاست. خودش سورس نیست (رمزنگاری‌شده)، ولی یعنی هر کسی می‌تواند بستهٔ ما را بردارد؛
  همان تصمیمی که قبلاً گرفتی (عمومی بماند) این را هم پوشش می‌دهد.

## ۸) حالت قفل (جدید): بدون لایسنس، افزونه هیچ‌چیز نیست

از این نسخه، اگر لایسنس فعال نباشد افزونه **هیچ بخشی از خودش را بارگذاری نمی‌کند**:

| چه چیزی | بدون لایسنس |
|---|---|
| منو و صفحات پیشخوان | ثبت نمی‌شود (در نوار کنار هیچ اثری نیست) |
| ویجت و شورت‌کد روی سایت | اجرا نمی‌شود |
| API و REST | ثبت نمی‌شود |
| اینباکس، آمار، مخاطبین، اعلان‌ها | غیرفعال |
| فعال‌سازی افزونه | بلافاصله لغو و پیام داده می‌شود |
| پیام مدیر | «برای فعال‌سازی افزونه، بخش‌های دامنه خود را در سایت راست‌چین فعال نمایید.» |

مکانیزم: در `gapineh.php`، بلافاصله پس از بارگذاری لایسنس، شرط
`! Gapineh_License::is_pro()` بررسی می‌شود؛ اگر درست باشد فقط
`includes/class-license-lock.php` بارگذاری و سپس با `return` از ادامهٔ فایل
جلوگیری می‌شود. هیچ include دیگری اجرا نمی‌شود.

**راه فرار برای توسعه/استیج:** در `wp-config.php`:

```php
define( 'GAPINEH_DEV', true );
```

یا در قالب/افزونهٔ دیگری: `add_filter( 'gapineh_allow_unlicensed', '__return_true' );`

⚠️ **زنجیرهٔ وابستگی که باید بدانی:** لایسنس ← ionCube Loader ← هاست.
اگر هاست `ionCube Loader` نداشته باشد، وضعیت `no_loader` می‌شود و **افزونه کامل قفل
می‌ماند** (فقط پیام می‌دهد). یعنی تا وقتی Loader را فعال نکنی، با این حالت قفل هیچ
بخشی از محصول روی سایت کار نمی‌کند. ترتیب درست: اول ionCube را روی هاست فعال کن،
بعد دامنه را در پنل راست‌چین فعال کن، بعد افزونه را روشن کن.
