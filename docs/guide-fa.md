# راهنمای راه‌اندازی پاسخ‌بان

این همان راهنمای PDF است، به شکل متن باز تا در گیت‌هاب و روی صفحهٔ مستندات هم خوانده شود.
همه‌جا «پاسخ‌بان ← تنظیمات» یعنی پیشخوان وردپرس ← منوی پاسخ‌بان ← تنظیمات.

---

## ۱) نصب

۱. بستهٔ ZIP را از اتحاد وردپرس بگیرید.
۲. پیشخوان ← افزونه‌ها ← «بارگذاری افزونه» ← انتخاب فایل ← «الان نصب کن» ← «فعال کردن».
۳. اگر از نسخهٔ قبل آپدیت می‌کنید، همان فایل جدید را نصب کنید؛ تنظیمات، مکالمات،
   مخاطبین و ایندکس دانش **حفظ می‌شوند**.

> نصب از راه «بارگذاری افزونه» فقط با فایل ZIP افزونه کار می‌کند. اگر خطای
> «افزونه پیدا نشد» دیدید، فایل ZIP اشتباهی (مثلاً فایل پشتیبان کامل سایت) انتخاب شده است.

## ۲) حذف و نگهداری داده

- **غیرفعال کردن** هیچ چیزی را حذف نمی‌کند.
- **حذف کامل** افزونه هم فقط در صورتی داده‌ها را پاک می‌کند که در «تنظیمات ← امنیت و داده»
  گزینهٔ «حذف داده‌ها هنگام حذف پلاگین» روشن باشد.
- پیش از حذف یا جابه‌جایی سایت: «تنظیمات ← امنیت و داده ← صادر کردن تنظیمات» و یک فایل پشتیبان
  از پایگاه‌داده بگیرید. فایل JSON تنظیمات شامل کلید API است؛ آن را جای امن نگه دارید.

## ۳) راه‌اندازی هشت‌مرحله‌ای

| # | تب | چه کاری |
|---|---|---|
| ۱ | اتصال | سرویس هوش مصنوعی، کلید API و مدل را انتخاب کنید ← ذخیره ← «آزمایش اتصال» |
| ۲ | دستیار و دانش | «پاسخ بر اساس محتوای سایت» را روشن کنید، برای دقت بهتر جست‌وجوی معنایی را فعال و «ساخت / به‌روزرسانی ایندکس» را بزنید |
| ۳ | چت آنلاین | عنوان پنل، پیام خوش‌آمد، جای حباب، فرم پیش‌گفت‌وگو، ارسال فایل و ساعات پاسخ خودکار |
| ۴ | ظاهر | اندازه و شفافیت پنل، رنگ‌ها، و روشن/تاریک بودن خودکار |
| ۵ | اعلان‌ها | ایمیل، تلگرام، بله یا پیامک — فقط بعد از واردکردن اطلاعات همان سرویس فعال کنید |
| ۶ | تیم | افزودن کاربران با نقش «اپراتور پاسخ‌بان»، واگذاری نوبتی و ساعت کاری |
| ۷ | امنیت و داده | محدودیت درخواست به‌ازای هر IP، مدت نگهداری مکالمات، گزینهٔ حذف داده هنگام حذف پلاگین |
| ۸ | بررسی سلامت | «اجرای همهٔ بررسی‌ها» ← در صورت ⚠ متن راهنمای رفع را بخوانید و در صورت نیاز گزارش متنی را برای پشتیبانی بفرستید |

## ۴) ذخیرهٔ تنظیمات

همهٔ فیلدها یک فرم واحدند؛ دکمهٔ بالای صفحه، پایین صفحه و نوار چسبان هر سه همان فرم را ذخیره می‌کنند.
اگر دکمه عمل نکرد:

۱. کش مرورگر و کش افزونهٔ کش/CDN را پاک کنید.
۲. کنسول مرورگر را باز کنید؛ خطای جاوااسکریپت یعنی فایل افزونه کامل آپلود یا جایگزین نشده است.
۳. مطمئن شوید حساب شما دسترسی «مدیریت گزینه‌ها» دارد (نقش مدیر کل).
۴. اگر چند افزونهٔ بهینه‌سازی/MINIFY دارید، موقتاً خاموششان کنید تا فایل‌های JS دست‌نخورده سرو شوند.

## ۵) عیب‌یابی رایج

| نشانه | بررسی |
|---|---|
| پاسخ هوش مصنوعی خالی است | اول «ذخیرهٔ تنظیمات»، بعد «آزمایش اتصال»؛ مدل و نشانی سرویس را چک کنید؛ موجودی حساب سرویس را ببینید |
| ویجت در سایت دیده نمی‌شود | تب «ظاهر» و «عمومی» → فعال بودن نمایش ویجت را بررسی کنید؛ کش سایت/CDN را پاک کنید؛ مطمئن شوید قالب، تابع پایانی صفحه را صدا می‌زند |
| پاسخ بر اساس محتوای سایت ضعیف است | ایندکس دانش را دوباره بسازید؛ محتوای پراکنده را در یک برگه یا دسته جمع کنید؛ جست‌وجوی معنایی را روشن کنید |
| اعلان تلگرام/بله نمی‌رسد | «بررسی سلامت» را اجرا کنید؛ اگر سرویس از هاست شما مسدود است، مسیر رله را طبق راهنمای همان تب تنظیم کنید |
| پیامک ارسال نمی‌شود | نام کاربری/رمز و امضای متن در پنل سرویس پیامک؛ شمارهٔ فرستنده باید ثبت‌شده باشد |
| تاریخ‌ها دو ساعت جابه‌اند | ناحیهٔ زمانی از تنظیمات عمومی وردپرس خوانده می‌شود؛ همان‌جا را درست کنید |
| تصویر/فایل برای مشتری باز نمی‌شود | کش CDN روی پوشهٔ آپلود، و محدودیت حجم فایل در همان تب «چت آنلاین» |
| تنظیمات بعد از فعال‌سازی صفر شد | یعنی افزونه حذف و دوباره نصب شده (نه غیرفعال). گزینهٔ حذف داده را خاموش کنید و از JSON پشتیبان استفاده کنید |

## ۶) برندسازی سفید

در تب «ظاهر»: فعال‌کردن برندسازی سفید، نام برند، نشانی برند و لوگوی مشتری را می‌گیرید.
با این حالت لوگوی پیش‌فرض، نام و پابرگ پاسخ‌بان از رابط کاربری حذف می‌شود.
برای مشتری، فایل ZIP همان نسخهٔ استاندارد را نصب کنید — فایل اصلاح‌شدهٔ دستی بسازید،
در به‌روزرسانی بعدی تغییرات شما از بین می‌رود.

## ۷) امنیت، کوتاه

- کلید API فقط روی سرور شما ذخیره می‌شود و به مرورگر بازدیدکننده نمی‌رود؛ در هیچ پاسخ یا فایل JS نبوده و نیست.
- برای هر مکالمه یک کلید نشست محلی ساخته می‌شود؛ بدون آن، نوشتن در همان گفت‌وگو ممکن نیست.
- محدودیت تعداد درخواست به‌ازای هر IP را روی سایت شلوغ بین ۱۰ تا ۲۰ بگذارید.
- HTTPS را فعال نگه دارید؛ بدون آن کوکی‌های نشست و ورودی صوتی مرورگر درست کار نمی‌کنند.
- گزارش «بررسی سلامت» را می‌توانید مستقیم در تیکت بفرستید؛ کلیدهای API در آن پوشانده می‌شوند.

## ۸) پیش از هر به‌روزرسانی

۱. «صادر کردن تنظیمات» ← فایل JSON را نگه دارید.
۲. یک پشتیبان معمولی از پایگاه‌داده.
۳. پس از نصب نسخهٔ جدید: «بررسی سلامت» را اجرا کنید و یک پیام آزمایشی بفرستید.
