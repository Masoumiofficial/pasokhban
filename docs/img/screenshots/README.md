# اسکرین‌شات‌های واقعی محصول

اینجا عمداً خالی است؛ تصویرهای ساختگی به‌جای اسکرین‌شات واقعی نگذارید.

برای گرفتن تصویر آمادهٔ انتشار:

۱) یک نصب تمیز روی دامنهٔ تست — نه سایت مشتری
۲) نام، ایمیل و شمارهٔ اپراتور را با دادهٔ ساختگی پر کنید؛ در اینباکس هم فقط دو سه پیام آزمایشی بگذارید
۳) فیلدهای کلید API، توکن ربات و پنل پیامک **خالی** بماند (اسکرین‌شات تب اتصال با فیلد خالی بگیریم)
۴) عرض مرورگر ۱۴۴۰، مقیاس ۱x، خروجی PNG سپس فشرده‌سازی:
   `convert shot.png -resize 1200x -strip -dither FloydSteinberg -colors 256 shot-opt.png`
۵) نام‌گذاری: `settings-conn.png` `settings-assistant.png` `settings-chat.png` `settings-look.png`
   `widget-chat.png` `widget-white-label.png` `inbox.png` `health.png`
۶) پس از افزودن، در `README.md` بخش «نمای کلی» را با چند خط باز کنید و تصاویر را لینک کنید.

هرگز فایل ZIP افزونه، تکه‌کد، لاگ سرور یا خروجی واقعی دیتابیس را جای تصویر پیوست نکنید.
