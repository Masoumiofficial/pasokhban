03

ارتباط با تیم

تلگرام، بله و پیامک

✈️ تلگرام مستقیم

  1. در BotFather ربات بسازید و Token بگیرید.
  2. ربات را به گروه اضافه و دسترسی لازم را بدهید.
  3. Token و Chat ID را در اعلان‌ها وارد کنید.
  4. ذخیره و تست اتصال را اجرا کنید.

☁️ رله Google برای تلگرام

  1. در script.google.com پروژه جدید بسازید.
  2. کل محتوای فایل google-relay.gs افزونه را جایگزین کد پیش‌فرض کنید.
  3. خط `SECRET` را با کلید تصادفی بلند عوض کنید.
  4. Deploy ← New deployment ← Web app را بزنید.
  5. Execute as را روی Me و Who has access را روی Anyone بگذارید.
  6. URL پایان‌یافته با `/exec` را در تنظیمات رله وارد کنید.
  7. همان SECRET را در وردپرس قرار دهید.
  8. بعد از هر تغییر: Manage deployments ← Edit ← New version.
var SECRET = 'کلید-تصادفی-طولانی-شما';

🟦 کانال بله

  1. توکن ربات بله و شناسه گفتگو را وارد کنید.
  2. اعلان یک‌طرفه یا پاسخ دوطرفه را انتخاب کنید.
  3. سایت باید HTTPS عمومی داشته باشد.
  4. Webhook را ثبت و تست کنید.

📱 پیامک و ایمیل

  1. ارائه‌دهنده پیامک را انتخاب کنید.
  2. API Key، شماره فرستنده و شماره مدیر را وارد کنید.
  3. اعلان مدیر و بازدیدکننده را جداگانه فعال کنید.
  4. فاصله اعلان را برای جلوگیری از تکرار تنظیم کنید.

05

اگر مشکلی پیش آمد

عیب‌یابی استاندارد

تست اتصال AI خطا می‌دهد +

API Key، مدل، Base URL و دسترسی هاست به اینترنت را بررسی کنید. ابتدا ذخیره کنید و بعد تست بگیرید.

ویجت در سایت دیده نمی‌شود +

نمایش ویجت و چت آنلاین را فعال کنید، کش سایت/CDN را پاک کنید و با مرورگر خصوصی تست کنید.

تلگرام پیام نمی‌فرستد +

Token، Chat ID، عضویت ربات در گروه، SECRET و URL دارای /exec را بررسی کنید. اگر رله تغییر کرده، نسخه جدید Deploy کنید.

تنظیمات ذخیره نمی‌شود +

با مدیرکل وارد شوید، کش را پاک کنید و مطمئن شوید افزونه دوباره حذف و نصب نشده است. از دکمهٔ صادر کردن تنظیمات پشتیبان بگیرید.
