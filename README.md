# گپینه

**گپینه** یک افزونهٔ وردپرس برای پشتیبانی هوشمند و پاسخ‌گویی آنلاین است؛ چت هوشمند، دانش واقعی سایت و اپراتور انسانی را در یک تجربهٔ فارسی و راست‌چین کنار هم قرار می‌دهد.

این مخزن **مخزن خصوصیِ توسعه** است: صفحهٔ معرفی، مستندات، ابزارهای انتشار و بسته‌های ZIP اینجا
نگهداری می‌شوند. ویترین عمومی محصول `etehadwp/gapineh` است (فقط مستندات؛ بدون کد).

> ⚠️ **باید private بماند.** بستۀ ZIP افزونه (سورس کامل) در این مخزن کامیت می‌شود؛ اگر visibility
> این مخزن `public` باشد، سورس محصول برای همه قابل دانلود است. پیش از انتشار لانچ بررسی کن.

## قابلیت‌های اصلی

- چت هوشمند مبتنی بر دانش سایت، با امکان ورود اپراتور انسانی در همان مکالمه
- اینباکس یکپارچه در پیشخوان وردپرس با واگذاری مکالمه و پیشنهاد پاسخ
- پشتیبانی از ووکامرس برای استعلام امن سفارش، قیمت و موجودی
- اعلان‌ها از طریق تلگرام، بله، پیامک و ایمیل
- رابط کاربری فارسی، تقویم شمسی و ارقام فارسی

## یادداشت

- کلید API سرویس هوش مصنوعی در سمت سرور نگهداری می‌شود و تنظیمات آن از پیشخوان وردپرس کنترل می‌شود.
- غیرفعال‌سازی افزونه تنظیمات و مکالمات را حذف نمی‌کند.
- **حذف کامل افزونه** هم از نسخۀ ۱.۰.۰ داده‌ای را پاک نمی‌کند، مگر اینکه کاربر خودش
  «تنظیمات ← امنیت و داده ← حذف داده‌ها هنگام حذف پلاگین» را روشن کرده باشد (پیش‌فرض: خاموش).
- فونت CDN، صدای پیام و نگهداری ۳۶۵‌روزۀ مکالمات هم از همین نسخه پیش‌فرض‌های محافظه‌کارانه دارند؛
  جزئیات در `docs/RELEASE-NOTES-1.0.0.md`.

## نشان برند

نشان گپینه: حبابِ گفتگو با حرفِ «گ»، به‌صورت SVG خودبسنده (بدون فونت). فایل‌ها و
قواعد استفاده در `docs/marketing/logo/` — نشانه، نسخهٔ تک‌رنگ/سفید، لوک‌آپ افقی با و
بدون شعار، و خروجی PNG. بازتولید با `tools/build-logo.py`.

## ابزارهای انتشار

| ابزار | کار |
|---|---|
| `tools/build-assets.sh <ریشۀ افزونه>` | ساخت `*.min.js` / `*.min.css` با terser + csso |
| `tools/lint-php.js <ریشۀ افزونه>` | پارس همه فایل‌های PHP با گرامر ۷.۴ و ۸.۳ (php-parser) |
| `tools/verify-release.py <افزونه> [مخزن عمومی]` | دروازۀ نشتی، سازگاری نسخه، ساختار uninstall، استاتیک یتیم، `.min`، static-call |
| `tools/build-guide-pdf.py` | ساخت PDF راهنما از `docs/guide-fa.md` |
| `tools/rename-brand.py <درخت> --slug --label --camel [--apply]` | تغییرنام کامل برند (کلاس‌ها، جداول، گزینه، REST، فایل‌ها، متن فارسی) — گزارش `docs/NAMING-2026-10-fa.md` |
