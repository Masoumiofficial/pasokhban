# پاسخ‌بان

**پاسخ‌بان** یک افزونهٔ وردپرس برای پشتیبانی هوشمند و پاسخ‌گویی آنلاین است؛ چت هوشمند، دانش واقعی سایت و اپراتور انسانی را در یک تجربهٔ فارسی و راست‌چین کنار هم قرار می‌دهد.

این مخزن به‌عنوان **Showcase Repository** پاسخ‌بان است: صفحهٔ معرفی محصول، راهنمای کامل و مستندات عمومی در آن نگهداری می‌شوند. سورس کامل افزونه و بسته‌های نصب (ZIP) در این مخزن قرار ندارند.

## ساختار مخزن

| مسیر | محتوا |
|---|---|
| `product-landing/` | صفحهٔ فروش و راهنمای آنلاین محصول (HTML، CSS، JavaScript و فایل رلهٔ گوگل) |
| `docs/` | مستندات عمومی؛ شامل راهنمای کامل فارسی (PDF) |

## صفحهٔ معرفی محصول

فایل‌های `product-landing/` یک صفحهٔ ایستا هستند و نیازی به سرور پویا یا وابستگی ساخت ندارند.

**استقرار:** محتوای پوشهٔ `product-landing/` را داخل مسیر `public_html/pasokhban/` هاست خود قرار دهید. پس از آن صفحهٔ اصلی از `index.html` و راهنمای کامل از `guide.html` در دسترس خواهد بود.

## راهنما

- راهنمای کامل راه‌اندازی (PDF): [`docs/pasokhban-guide-fa.pdf`](docs/pasokhban-guide-fa.pdf)
- راهنمای تعاملی آنلاین: `product-landing/guide.html`

## قابلیت‌های اصلی

- چت هوشمند مبتنی بر دانش سایت، با امکان ورود اپراتور انسانی در همان مکالمه
- اینباکس یکپارچه در پیشخوان وردپرس با واگذاری مکالمه و پیشنهاد پاسخ
- پشتیبانی از ووکامرس برای استعلام امن سفارش، قیمت و موجودی
- اعلان‌ها از طریق تلگرام، بله، پیامک و ایمیل
- رابط کاربری فارسی، تقویم شمسی و ارقام فارسی

## یادداشت

- کلید API سرویس هوش مصنوعی در سمت سرور نگهداری می‌شود و تنظیمات آن از پیشخوان وردپرس کنترل می‌شود.
- غیرفعال‌سازی افزونه تنظیمات و مکالمات را حذف نمی‌کند؛ حذف داده‌ها فقط با حذف کامل افزونه انجام می‌شود.
