گفتگوی آنلاین و دستیار هوشمند برای وردپرس، همراه با اینباکس اپراتور در پیشخوان.

== Description ==

گپینه یک پنجرهٔ گفتگوی شناور و شورت‌کد [gapineh] برای سایت وردپرسی فراهم می‌کند. پاسخ هوشمند نیازمند اتصال به سرویس سازگار و تنظیم کلید API و مدل است. هزینه و دسترسی به مدل‌ها به ارائه‌دهندهٔ سرویس بستگی دارد.

امکانات افزونه، بسته به تنظیمات و سرویس‌های متصل:

* گفتگوی بازدیدکننده با دستیار هوشمند یا اپراتور انسانی؛ اینباکس، مخاطبین و آمار در پیشخوان.
* تنظیم ظاهر، حالت روشن و تاریک، فرم پیش‌گفتگو و ارسال فایل با پسوندهای مجاز قابل تنظیم.
* استفاده از محتوای سایت برای پاسخ‌گویی؛ جست‌وجوی معنایی اختیاری به سرویس embedding و ساخت ایندکس نیاز دارد و کیفیت نتیجه به محتوا و سرویس وابسته است.
* ابزار پیشنهاد پاسخ و خلاصهٔ گفتگو برای اپراتور، با استفاده از سرویس هوش مصنوعی تنظیم‌شده.
* قابلیت‌های مرتبط با محصولات و بررسی سفارش، در صورت نصب و تنظیم ووکامرس.
* نقش اپراتور، واگذاری گفتگو، ساعت کاری و تنظیم اعلان‌ها. پیامک، تلگرام و بله نیازمند تنظیم سرویس مربوط هستند.
* ذخیرهٔ گفتگوها در پایگاه‌دادهٔ وردپرس، تنظیم مدت نگهداری و محدودسازی نرخ درخواست.

نمایش تدریجی پاسخ هوش مصنوعی در این نسخه موقتاً غیرفعال است؛ پاسخ پس از دریافت کامل نمایش داده می‌شود. اتصال به API، زمان پاسخ و هزینه‌های احتمالی به سرویس انتخابی و شرایط سایت بستگی دارند.

== Installation ==

1. فایل ZIP را از پیشخوان وردپرس، در بخش افزونه‌ها ← افزودن ← بارگذاری افزونه نصب و فعال کنید.
2. در «گپینه ← تنظیمات» سرویس، کلید API و مدل را وارد و ذخیره کنید؛ سپس اتصال را آزمایش کنید.
3. تنظیمات چت و امکانات اختیاری را متناسب با سایت خود بررسی کنید. گفتگوها در «گپینه ← گفتگو آنلاین» در دسترس‌اند.
4. برای قراردادن چت در یک صفحه می‌توانید از شورت‌کد [gapineh] استفاده کنید.
5. برای جست‌وجوی معنایی، پس از تنظیم سرویس embedding، قابلیت مربوط را فعال و ایندکس را بسازید.

جزئیات بیشتر در فایل GUIDE-fa.md داخل بسته آمده است.

== FAQ ==

= آیا استفاده از هوش مصنوعی بدون کلید API امکان‌پذیر است؟ =

خیر؛ برای پاسخ هوشمند باید سرویس سازگار، مدل و کلید API معتبر تنظیم شوند. ارائه‌دهنده ممکن است برای درخواست‌ها هزینه دریافت کند.

= آیا پاسخ به‌صورت تدریجی نمایش داده می‌شود؟ =

خیر. نمایش تدریجی در این نسخه موقتاً غیرفعال است و پاسخ پس از دریافت کامل نشان داده می‌شود.

= آیا بخش سفارش به ووکامرس نیاز دارد؟ =

بله؛ قابلیت‌های مربوط به محصولات و سفارش‌های ووکامرس به نصب و تنظیم ووکامرس وابسته‌اند.

= با حذف افزونه چه اتفاقی برای داده‌ها می‌افتد؟ =

به‌صورت پیش‌فرض گزینهٔ حذف داده‌ها هنگام حذف افزونه خاموش است. پیش از حذف یا به‌روزرسانی، از فایل‌ها و پایگاه‌دادهٔ سایت نسخهٔ پشتیبان تهیه کنید. مدت نگهداری گفتگوها نیز در تنظیمات قابل تغییر است و مقدار پیش‌فرض آن ۳۶۵ روز است.
